# أثر لتبادل الخبرات والمعرفة

منصة داخلية لمنسوبات متوسطة وثانوية البشائر الأولى، مبنية باستخدام PHP وMySQL وTailwind CSS عبر CDN.

## المتطلبات

- PHP 8.1 أو أحدث، مع إضافات `pdo_mysql` و`mbstring` و`fileinfo`.
- MySQL 8 أو MariaDB متوافق.
- Apache مع `mod_rewrite` غير مطلوب، و`AllowOverride All` لتفعيل ملفات الحماية `.htaccess`.
- اتصال بالإنترنت لتحميل Tailwind CSS من CDN.

## تشغيل المشروع على XAMPP

1. انسخي مجلد المشروع إلى `C:\xampp\htdocs\works\Exchanging-experiences`.
2. شغّلي Apache وMySQL من لوحة تحكم XAMPP.
3. افتحي phpMyAdmin، ثم استوردي الملف `database/schema.sql`. ينشئ الملف قاعدة البيانات `teacher_experiences` والجداول المطلوبة.
4. عند تحديث قاعدة موجودة، خذي نسخة احتياطية أولاً. طبّقي ملفات الترحيل بالترتيب من مجلد `database/migrations` على قاعدة `teacher_experiences` من phpMyAdmin؛ ويحوّل ترحيل `20261022_01_utf8mb4_database_charset.sql` ترميز القاعدة وجميع جداول المنصة إلى `utf8mb4`، ثم يضيف `20261022_02_admin_dashboard.sql` سبب رفض الخبرة وسجل إجراءات الإدارة. أعيدي استيراد `database/schema.sql` إذا احتجتِ إلى إنشاء جداول أضيفت في إصدار أحدث.
5. انسخي `config/database.example.php` إلى `config/database.php`، ثم راجعي إعدادات الاتصال لتطابق إعداد MySQL لديك. يمكنك بدلاً من ذلك ضبط متغيرات البيئة `DB_HOST` و`DB_PORT` و`DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD`. ملف `config/database.php` محلي ومستثنى من Git حتى لا تُرفع بيانات الاتصال.
6. من سطر الأوامر شغّلي:

   ```powershell
   C:\xampp\php\php.exe C:\xampp\htdocs\works\Exchanging-experiences\create_admin.php
   ```

   أدخلي اسم المديرة وبريدها وكلمة مرور قوية. كلمة المرور تُكتب ظاهرة في نافذة الأوامر؛ تجنبي تشغيل الأمر في جلسة مشتركة.
7. افتحي `http://localhost/works/Exchanging-experiences/`.
8. سجّلي الدخول بحساب الإدارة. تنشئ المعلمات حساباتهن من رابط **إنشاء حساب جديد** في الموقع، ويمكن للإدارة متابعة الحسابات وتفعيلها أو إيقافها من صفحة **إدارة الحسابات**.

إذا كان اسم مجلد المشروع مختلفاً، يحدد التطبيق عنوانه الأساسي تلقائياً. ويمكن تجاوز ذلك بمتغير البيئة `APP_BASE_URL`.

## خريطة المجلدات

```text
.
├── admin/                  لوحة الإدارة وإدارة الحسابات ومراجعة المشاركات
├── app/                    تهيئة التطبيق، الدوال المساعدة، والتحقق من الصلاحيات
├── assets/css/             تنسيقات إضافية فوق Tailwind CDN
├── assets/js/              تفاعلات النماذج والتنقل
├── config/                 إعداد اتصال MySQL
├── database/               مخطط إنشاء قاعدة البيانات والجداول
├── experiences/            استعراض الخبرات، عرضها، إضافتها، وتنزيل مرفقاتها
├── includes/               ترويسة وتذييل مشتركَان
├── storage/uploads/        مرفقات الخبرات (يُمنع الوصول المباشر إليها)
├── create_admin.php        إنشاء أول مدير من سطر الأوامر فقط
├── index.php               الصفحة التعريفية الرئيسية
├── login.php               تسجيل الدخول
└── logout.php              إنهاء الجلسة
```

## المزايا الموجودة

- صفحة تعريفية عربية ومتجاوبة تعرض رسالة المنصة وأسماء قيادة المدرسة.
- حسابات للمديرة والمعلمات، مع تخزين كلمات المرور باستخدام `password_hash`.
- تسجيل عام للمعلمات مع التحقق من البيانات ورمز CSRF ومصيدة حقل مخفي لتقليل التسجيل الآلي؛ لا يُنشأ حساب عند تعبئة حقل المصيدة.
- تخزين أسماء المستخدمين العربية باستخدام `utf8mb4` وإمكانية تحديث الاسم الظاهر لحساب الإدارة من صفحة إدارة الحسابات.
- إضافة الخبرات وتصنيفها، والبحث والتصفية حسب المجال.
- صفحة **خبراتي** للمعلمات لعرض مشاركاتهن وحالاتها، وتعديلها مباشرةً في نموذج إضافة الخبرة نفسه أو حذف المشاركة ومرفقاتها.
- إرفاق ملفات تعليمية آمنة بالخبرة، مع تنزيلها للمستخدمين المخولين فقط.
- تفاصيل الخبرة والتعليقات والإعجابات.
- لوحة إدارة تعرض إحصاءات المستخدمين والخبرات، مهام المراجعة، أحدث النشاطات، وإجراءات الإدارة المسجلة.
- إدارة المستخدمين بالبحث، وعرض نشاط كل معلمة، وتفعيل الحسابات أو إيقافها.
- إدارة المجالات التربوية من لوحة الإدارة، بما في ذلك إضافة المجالات وتعديلها وحذف المجالات غير المستخدمة.
- إدارة الخبرات بالبحث والتصفية حسب المجال والحالة والتاريخ، مع تسجيل سبب إخفاء/رفض الخبرة.
- حذف الخبرة لصاحبتها أو للإدارة، وحذف حساب المعلمة نهائياً بعد التأكيد؛ يشمل الحذف المحتوى والتعليقات والإعجابات، مع تنظيف ملفات الخبرات المرفقة.
- استعلامات قاعدة بيانات مجهّزة، ترميز لمخرجات المستخدم، ورمز CSRF للنماذج.

## المجالات وحالات المشاركة

تُدار المجالات من لوحة الإدارة. لا يمكن حذف مجال مرتبط بخبرات موجودة؛ يمكن تعديل اسمه بدلاً من ذلك. لتحديث قاعدة بيانات موجودة، شغّلي `database/migrations/20261022_03_experience_categories.sql` بعد أخذ نسخة احتياطية.

حالات المشاركة: منشورة، قيد المراجعة، ومخفية. النشر الفوري هو الافتراضي؛ ويمكن تغيير الحالة من لوحة المراجعة.
